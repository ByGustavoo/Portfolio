# Portfólio · Gustavo Correa

Portfólio pessoal de Gustavo Chauar Correa, desenvolvedor Java back-end na VR Software.

Página única com as seções Início, Sobre, Competências, Experiência, Projetos e Contato, tema claro e escuro (segue o sistema e lembra a escolha do visitante) e layout responsivo.

## 🚀 Ferramentas utilizadas

* HTML semântico
* CSS (Grid, Flexbox, custom properties)
* JavaScript sem dependências

## 📁 Estrutura

* `index.html`: página do portfólio
* `about.html`: redireciona o endereço antigo para a seção Sobre
* `Styles/style.css`: estilos e tokens de tema
* `scripts/main.js`: tema, menu mobile e navegação ativa
* `assets/`: imagens

## ▶️ Como rodar localmente

```bash
python -m http.server 5500
```

Depois, abra `http://localhost:5500`.
